# 반도체 제조 공정 데이터 분석 및 불량 예측 모델링

## 프로젝트 소개
본 프로젝트는 반도체 제조 공정에서 발생하는 센서 데이터와 공정 기록을 바탕으로 **수율 향상 및 불량 원인 분석**을 수행한 종합 데이터 분석 프로젝트입니다. 
통계적 공정 관리(SPC) 기법을 활용하여 공정의 이상 상태를 탐지하고, 머신러닝 모델을 도입하여 불량 칩 발생을 사전에 예측하며, 최종적으로 불량률을 최소화할 수 있는 핵심 공정 파라미터의 최적 구간을 도출했습니다.

## 핵심 목표
1. **공정 이상 탐지 (SPC):** C-관리도를 활용하여 Wafer 단위의 불량 칩 수를 모니터링하고 이상 공정(Out of Control) 식별.
2. **탐색적 데이터 분석 (EDA):** 생산 부하(Path) 및 주요 공정 변수가 불량률에 미치는 영향 분석.
3. **불량 예측 모델링:** 제조 공정 데이터의 고질적인 클래스 불균형 문제를 해결하고, 재현율(Recall)과 F1-Score를 극대화하는 예측 모델 구축.
4. **공정 최적화:** 주요 설비 파라미터(Source Power, RTA Temp, Bake Temp 등)의 최적 운전 구간 산출을 통한 수율 개선 가이드 제시.

## 기술 스택
- **Language:** Python
- **Data Analysis & Processing:** Pandas, NumPy
- **Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-learn, Imbalanced-learn (SMOTE)

## 주요 분석 내용 및 결과

### 1. 통계적 공정 관리 (C-관리도 분석)
- Wafer별 불량 칩 발생 빈도를 추적하기 위해 C-관리도를 시각화했습니다.
- 관리 상한선(UCL)과 하한선(LCL)을 설정하여, 통제 범위를 벗어나는 이상 공정(Target)의 비율을 계산하고 이를 원인 분석의 타겟으로 삼았습니다.

### 2. 생산 부하 및 경로(Path) 분석
- 칩이 거쳐간 세부 공정 경로(Path)에 따른 불량률 차이를 분석했습니다.
- 불량률 상위 4개 경로와 하위 4개 경로를 교차 비교하여, 특정 설비 조합이나 생산 부하가 수율에 미치는 병목 현상을 확인했습니다.

### 3. 머신러닝 모델링 및 성능 비교 평가
본 프로젝트의 핵심 과제 중 하나는 '정상 칩이 압도적으로 많은 불균형 데이터(Imbalanced Data)' 환경에서 불량 칩을 정확히 찾아내는 것이었습니다. 이를 위해 다양한 알고리즘을 비교하고 최적의 모델을 선정했습니다.

* **데이터 불균형 처리 (SMOTE 적용):** * 원천 데이터의 심각한 클래스 불균형 문제를 해결하기 위해 SMOTE(Synthetic Minority Over-sampling Technique) 기법을 적용하여 Minority Class(불량) 데이터를 오버샘플링했습니다.
  * 적용 전후의 모델 성능을 교차 비교하여 샘플링 기법의 유효성을 검증했습니다.
* **비교 알고리즘:**
  * Logistic Regression, Random Forest, XGBoost, LightGBM 등 다양한 선형 및 트리 기반 앙상블 모델을 학습하고 성능을 대조했습니다.
* **핵심 평가 지표 선정 및 결과:**
  * 제조업 특성상 실제 불량을 정상으로 오분류할 때 발생하는 비용이 훨씬 크기 때문에, 단순 정확도(Accuracy)가 아닌 **재현율(Recall)**과 **F1-Score**를 최우선 지표로 설정했습니다.
  * **비교 결과:** [최종 선택한 모델명, 예: XGBoost] 모델이 SMOTE 적용 후 Recall [0.00] 및 F1-Score [0.00]을 기록하여, 다른 모델 대비 불량 탐지 능력이 가장 우수함을 확인하고 최종 모델로 채택했습니다.
  * *(참고: 상세한 모델별 성능 지표 비교 그래프는 `notebooks/반도체 종합 프로젝트2 모델평가.ipynb`에서 확인하실 수 있습니다.)*

### 4. 핵심 파라미터 최적 구간 도출
- 예측 모델과 데이터 분포를 기반으로 불량률을 최소화할 수 있는 핵심 설비 변수의 최적 운전 구간을 산출했습니다.
  - *예시: Source_Power (49.34 ~ 49.98), temp_HMDS_bake (205.3 ~ 209.5), RTA_Temp 등*
- 이를 통해 단순 예측을 넘어 실제 제조 현장에 즉시 적용 가능한 엔지니어링 인사이트를 도출했습니다.
